# Abhinandan Garden Restaurant

Website for **Abhinandan Garden Restaurant**, Barapathar, Seoni. It showcases the restaurant's food menu, photo gallery, celebrations and events, and makes it easy for visitors to book a table or enquire about the lawn for parties.


## Pages

| File | Description |
| --- | --- |
| `index.html` | Homepage |
| `food-menu.html` | Food menu |
| `full-menu.html` | Full menu catalog |
| `gallery.html` | Photo gallery |
| `events.html` | Celebrations and events |
| `book-table.html` | Table booking enquiry |
| `party-enquiry.html` | Party dates and lawn availability enquiry |
| `profile.html` | Guest profile and concierge |

## Features

- Responsive design for mobile and desktop
- One-tap **Call** and **WhatsApp** buttons for enquiries
- Google Maps link to the restaurant
- Event and lawn booking enquiry

## Tech stack

- HTML
- Tailwind CSS (loaded from CDN)
- Google Fonts (Playfair Display, Plus Jakarta Sans)

## Run locally

No installation needed. Download or clone the repo and open `index.html` in your browser.

```bash
git clone https://github.com/<himanshuCoder2>/abhinandan-garden-restaurant.git
cd abhinandan-garden-restaurant
```

## Deployment

The site is static, so it deploys on Vercel with no build step. Every push to the `main` branch updates the live site automatically.
